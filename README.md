# Clay Tile Designer

A simple web tool for designing clay tile patterns on a grid of squares.

## Features

- Rectangular grid with a width and height you choose (in squares)
- Paint with a palette of colors (4 to start, add or remove as you like)
- Changing a palette color updates every square that uses it
- Random modes: randomize the whole grid, fill only empty squares, or paint with a random brush
- 3 × 3 repeat preview to see how the tile looks laid out
- Undo, clear, eraser, and PNG export
- Works on desktop and mobile; your design is saved in your browser

## Usage

Open `index.html` in a browser, or visit the GitHub Pages site for this repository.

To publish with GitHub Pages: go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
